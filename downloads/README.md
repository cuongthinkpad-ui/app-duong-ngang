# Cài bản thử Đường Ngang 0.1

Đây là APK phát triển để xem giao diện, chưa phải bản trực vận hành. Chưa kiểm thử đăng nhập/phân trang bằng web Visitec thật; tự kích và sơ đồ tàu thật chưa bật.

1. Mở file `DuongNgang-0.1.apk` trên GitHub, chọn **Download raw file** (biểu tượng tải xuống).
2. Chuyển file sang điện thoại Android 8.0 trở lên và mở để cài. Cho phép cài từ ứng dụng đang mở file khi Android yêu cầu.
3. Mở **Đường Ngang → Cài đặt → Xem giao diện bằng dữ liệu minh họa → Đóng**.

Không có tài khoản hoặc mật khẩu thử nghiệm được nhúng vào APK. Bản APK này ký bằng debug key, chưa dùng làm bản phát hành chính thức.
